1. RÉPARTITION SIMPLE ET ÉQUITABLE

ILYÈS — Base, validation et surveillance MVC

Crée la solution MVC et possède seul le dossier Data.

Code le circuit Labo → UER → Bureau → Conseil.

Code les rejets, l'historique et les contrôleurs associés.

Code le robot D1/D2, les anomalies et le dashboard.

Renforce la sécurité des contrôleurs, actions et services.


ISLEM — Articles, journaux et administration MVC

Code le dépôt et les règles des journaux ciblés.

Code la détection et la fusion des propositions en doublon.

Code la soumission réelle et le suivi éditeur.

Code paramètres, labos, UERs, utilisateurs et rôles.

Crée les contrôleurs, ViewModels, vues MVC et le manuel.


IMPORTANT

Aucun module IA n’est développé dans l’application.

Le LLM sert uniquement d’outil de développement pour accélérer le visuel des vues MVC .cshtml.

Les règles métier restent codées et testées dans les services ; les contrôleurs restent minces.

3. RÈGLES POUR TRAVAILLER SANS RÉUNION

Branche Ilyes :
ilyes — Data, validation, alertes, dashboard et sécurité.
